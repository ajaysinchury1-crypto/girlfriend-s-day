# 💕 START HERE - Happy Girlfriend's Day Website

Welcome! This is your complete guide to building and deploying the romantic website for your girlfriend.

## 🚀 5-Minute Quick Start

1. **Run locally**
   ```bash
   pnpm install
   pnpm dev
   ```
   Open http://localhost:3000

2. **Edit key content**
   - Relationship date: `components/ui/RelationshipTimer.tsx`
   - Love letter: `components/sections/LoveLetter.tsx`
   - Reasons: `components/sections/ReasonsILoveYou.tsx`

3. **Add your photos**
   - Put images in: `public/assets/gallery/`
   - Update: `components/sections/PhotoGallery.tsx`

4. **Deploy**
   ```bash
   git push  # to GitHub
   # Deploy from Vercel dashboard
   ```

5. **Share the link!** 💕

## 🚀 Deployment in 3 Steps

### Step 1: Push to GitHub
```bash
git add .
git commit -m "My romantic website"
git push
```

### Step 2: Connect to Vercel
1. Go to [vercel.com](https://vercel.com)
2. Click "New Project"
3. Select your GitHub repo
4. Click "Deploy"

### Step 3: Share!
- Copy your deployment URL
- Send to your girlfriend
- Watch her be amazed! 💕
